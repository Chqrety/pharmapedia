# 💊 Pharmapedia - Kamus Obat Digital

Pharmapedia adalah aplikasi web responsif bergaya *Modern Pop & Glassmorphism* yang dirancang sebagai "Kamus Obat Digital". Aplikasi ini memudahkan pengguna (terutama anak kost dan masyarakat umum) untuk mencari informasi detail mengenai obat-obatan, dosis, efek samping, dan aturan pakai.

Dilengkapi dengan sistem **Admin Dashboard** untuk mengelola *database* obat secara *real-time* menggunakan Supabase.

---

## ✨ Fitur Utama

### 🧑‍⚕️ User / Publik
* **Pencarian Real-time:** Cari obat berdasarkan nama atau kegunaan dengan cepat.
* **Detail Obat Komprehensif:** Menampilkan golongan obat, simbol (Bebas/Terbatas/Keras), kandungan, efek positif (manfaat), efek negatif (risiko), dosis, hingga interaksi obat.
* **Desain Ceria & Modern:** Menggunakan palet warna *pastel gradient* (Pink, Ungu, Peach) dengan efek *Glassmorphism* yang memanjakan mata.
* **Mobile-First Responsive:** Tampilan yang menyesuaikan dengan sempurna di layar HP, Tablet, maupun Desktop.

### 🔒 Admin Panel
* **Secure Login:** Akses dasbor dilindungi oleh sistem login.
* **Statistik Visual:** Ringkasan jumlah total obat berdasarkan kategori (Bebas, Terbatas, Keras).
* **Manajemen Data (CRUD):** Tambah data obat baru dengan *form* yang rapi dan hapus data lama dengan mudah.
* **Hybrid Layout:** Tampilan form "Sidebar" di Desktop untuk input cepat, dan form "Modal / Pop-up" di Mobile agar hemat ruang.

---

## 🛠️ Teknologi yang Digunakan

* **Framework:** [React.js](https://reactjs.org/) (via [Vite](https://vitejs.dev/))
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Database & BaaS:** [Supabase](https://supabase.com/) (PostgreSQL)
* **Routing:** [React Router DOM](https://reactrouter.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
